# Security

Veröffentliche keine Geräte-Serials, E-Mail-Adressen, IRC-Passwörter, privaten IP-Konfigurationen, Charakterdatenbanken, Screenshots oder Spielpakete. Lokale Dateien sind in `.gitignore` ausgeschlossen.

Sicherheitsmeldungen sollten ohne öffentliches Exploit-Beispiel an die Repository-Verantwortlichen gemeldet werden.
