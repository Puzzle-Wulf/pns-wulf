# Click-Event PNGs

Speichere pro Event eine möglichst eng zugeschnittene PNG-Datei unter:

```text
assets/click-events/<event-name>.png
```

Beispiel:

```text
assets/click-events/help_all.png
```

Alternativ kopiert dieser Befehl eine bearbeitete Datei an die richtige Stelle:

```bash
./pns-bot click-event template help_all --file ~/Desktop/help_all.png
```
